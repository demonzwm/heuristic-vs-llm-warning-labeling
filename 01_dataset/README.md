# dataset

This directory contains dataset construction material for the 1,027-warning evaluation set.

Inputs: raw warning reports and normalized/filtered warning data from CodeQL, CSA, and Cppcheck. Project source trees and build artifacts are intentionally excluded.

Outputs: processed benchmark files under `processed/benchmark/` and construction lineage files under `processed/normalized/` and `processed/preprocessing/`.

Paper mapping: dataset construction and benchmark description.
