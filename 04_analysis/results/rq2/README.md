# RQ2 agreement subset

`shared_llm_518_warning_level.csv` contains every warning for which the
DeepSeek-v4-flash and GPT-6 Luna LLM predictions agree. This selection uses
predictions only; ground truth is joined afterward for subgroup evaluation.

`shared_llm_518_summary.json` records the selection rule, all 518 selected
warnings, the 382 Heuristic/LLM agreements and 136 disagreements, both
disagreement directions, and GT/correctness counts for each group. The 136
disagreements consist of 114 Heuristic FP / shared LLM TP and 22 Heuristic TP /
shared LLM FP. `warning_level_agreement.csv` and `disagreement_matrix.csv`
cover the complete 1,027-warning benchmark separately.

All tables are regenerated by `04_analysis/scripts/build_final_paper_sync.py`.
