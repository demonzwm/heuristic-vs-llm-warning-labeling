benchmark metadata and code slice with the released GT, A, DeepSeek B,
GPT-6 Luna B, DeepSeek C, and GPT-6 Luna C labels. It is generated solely by
`04_analysis/scripts/build_final_paper_sync.py`. Do not use it as model input.
