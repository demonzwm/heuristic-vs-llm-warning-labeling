# final_dataset

This directory stores the final comparison dataset used by the paper-level analyses.

It is distinct from `01_dataset/`:

- `01_dataset/` explains how benchmark data was historically constructed and preserved,
- `final_dataset/` stores the final integrated comparison data used by RQ1 / RQ2 style analysis.

## Contents

- `final_comparison_dataset_1027.json`
  Final integrated dataset combining:
  - benchmark warning information,
  - formal heuristic prediction,
  - formal DeepSeek-v4-flash prediction,
  - formal GPT prediction,
  - ground-truth annotation.

## Boundary

Do not place raw data, normalized corpora, or preprocessing scripts here.
