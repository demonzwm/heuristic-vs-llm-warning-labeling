# Generic Fallback Schema

Use this schema for warnings outside the dedicated CWE-476 / CWE-787 coverage.

Procedure:
1. Identify the warning-specific defect condition.
2. Construct the Defect Hypothesis.
3. Construct the Safety Hypothesis.
4. Identify the semantic premises each hypothesis requires.
5. Verify visible supporting evidence and visible counter-evidence.
6. Mark unresolved premises explicitly.
7. Assess the structured warning-evolution evidence as historical context.
8. Resolve the competing hypotheses.
9. Output a final TP / FP label.
